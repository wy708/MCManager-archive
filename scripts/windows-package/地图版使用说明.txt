第一次安装（还没有 LeviLamina）
1. 在原游戏控制台输入 stop，等待正常保存并退出。
2. 把 ZIP 完整解压到游戏目录之外，例如 D:\MCManager。不要直接覆盖进游戏目录。
3. 双击 01-install.cmd，填写已有原版 BDS 1.26.61.1 的目录，例如 D:\Bedrock。
4. 双击 02-configure.cmd。档案和凭据会自动填好，不需要另建档案或复制密码。
5. 双击 03-start.cmd。保持这个窗口运行，以后使用它启动游戏服。

如果已经装了之前发的“不含地图接入包”
先正常停服并退出旧执行端，再在新包里运行 06-add-map-to-existing.cmd，填写原游戏目录。
然后运行 02-configure.cmd、03-start.cmd。以后保留并使用新安装包目录，不再运行旧包。
只接受对应版本的旧接入包；检测到已有地图或不同框架时会停止，避免覆盖你的配置。

包里有什么
- LeviLamina、精确匹配 1.26.61.1 的兼容层、采集插件。
- 原版 MipMap 及 Windows/版本兼容修复、方块状态和地狱洞穴层功能。
- 便携 Node.js 和 Python，不需要你另装，不修改系统环境变量。
- 网页控制台与备份执行端。备份默认放在游戏目录旁的 MCManagerBackups 文件夹。
- 不包含 Minecraft 服务端本体、世界、旧测试数据和测试账号。

世界和地图
- 安装不修改 bedrock_server.exe、worlds、server.properties、白名单或玩家权限。
- 框架的强制作弊指令开关关闭，保留你原有的生存/作弊设置。
- 第一次连接时地图空白正常，玩家上线、探索并加载区块后逐步出现地图；已生成地图可离线看。
- 不会自动扫描整个世界，也不会自动执行 loadmap。不要随意运行大范围 loadmap：原版命令会管理常加载区域，可能影响你已有的 tickingarea。
- 游戏机只需能向平台 HTTPS 配置端口 发起连接；地图不需要新开公网端口，玩家进服仍使用原游戏端口。

日常使用
- 网页中可查看日志、执行游戏命令、正常停服和重新开服。
- 关闭执行端窗口前，先在网页正常停服；机器重启后重新运行 03-start.cmd。
- 04-local-console.cmd 用于本地排查，不能和 03-start.cmd 同时运行。
- 05-verify-package.cmd 检查安装包是否完整。
- 不要移动或删除安装包目录，它包含游戏运行所需的 Python 和执行端。
- 仅支持 Windows x64 原版 BDS 1.26.61.1。本项目兼容版不代表所有第三方插件都兼容，也不要直接升级游戏版本。
