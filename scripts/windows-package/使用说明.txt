MCManager Windows BDS 1.26.61.1 接入包

适用：已有原版 Windows x64 BDS 1.26.61.1，尚未安装 LeviLamina。
这是本项目的精确版本兼容配置，不能保证其他第三方插件兼容。
本包不包含 Minecraft 服务端、世界、测试插件、测试数据或任何平台凭据。
自带 Node.js，仅供本包使用，不修改系统 PATH，也不需要另装 Node.js。

一、安装
1. 在原游戏控制台输入 stop，等正常保存并退出。
2. 将整个 ZIP 解压到游戏目录之外，例如 D:\MCManager-Windows。
   不要放在 D:\Bedrock 里面，也不要覆盖到游戏文件夹。
3. 双击 01-install.cmd，输入已有游戏服目录，例如 D:\Bedrock。
4. 程序校验原版服务端哈希，生成独立 bedrock_server_mod.exe，并安装框架与采集插件。
   不修改原始 bedrock_server.exe、worlds、server.properties、permissions.json、allowlist.json。
   如果发现已有框架或不匹配的服务端，会停止并提示，不强行覆盖。

二、连接网页
1. 打开 https://mc.example.com 并登录。
2. 在“服务器档案”添加你的真实服务器，记下该档案 UUID，并生成采集凭据。
3. 在“备份中心”的游戏主机区域，为同一个档案添加执行端，复制 mcmhost. 开头的凭据。
4. 双击 02-configure.cmd，依次粘贴 UUID、采集凭据、执行端凭据，选择游戏目录之外的备份目录。
   这两个凭据不是管理员账号密码，也不能互换。

三、启动
以后双击 03-start.cmd。这个窗口需要保持运行；日志、游戏命令、启停和备份由网页控制。
不要同时双击原 bedrock_server.exe，也不要用原启动器再次启动同一游戏目录。
网页“正常停服”只停止游戏，执行端窗口仍在线，可以在网页再次启动。
关闭执行端之前，先在网页正常停服。窗口关闭或电脑重启后，需要再次运行 03-start.cmd。
本包不自动设置 Windows 开机启动。

04-local-console.cmd 供尚未配置网页时查看框架本地控制台使用。与 03-start.cmd 二选一。
启动本地控制台时，若仍未配置采集凭据，插件会提示采集未启用，这是正常的。

四、说明
- 游戏服出站连接平台 HTTPS 配置端口，无需额外开放控制台端口。玩家连接仍使用你原有的游戏端口。
- 统计、聊天、玩家与容器状态、MCP 数据来源由采集插件提供；MCP 本身运行在 DSH 一侧。
- 这一包包含框架、版本兼容层、采集和控制台/备份执行端。原版 MipMap 地图另行接入，不在本包中。
- 安装失败请保留屏幕提示；版本不符不要改哈希、版本号或强行绕过检查。
- 配置后 config/host.json 和游戏目录中采集插件的 config.json 含私密凭据，不要发群或公开上传。
