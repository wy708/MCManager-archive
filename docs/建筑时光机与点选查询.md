# 建筑施工时光机与三维点选查询

入口：打开施工工程的公开链接，切换到「三维建筑」。本次只更新平台，不需要升级游戏服采集插件或 MCP 程序。

## 建筑施工时光机

- 平台启动 30 秒后开始检查，此后约每 5 分钟保存有变化的工程场景，不依赖网页打开。不增加游戏扫描次数、不强制加载区块。
- 下拉选择保存时间，或拖动时间轴查看历史；「播放建设过程」逐个显示已加载的画面，转换成功后再继续。可以暂停、返回最新画面、加载更早记录。
- 切换画面保持观察位置和缩放。模型高度仍只保存在当前浏览器。
- 各分段独立采集。时间轴标注的是平台保存时间，画面旁显示最近的采集时间，点选后显示该位置的采集时间；不能当作世界在某一瞬间的完整快照。
- 只保存检查时已经收到的数据，五分钟内的短暂搭建、拆除不保证留下三维画面。启用前只有已有阶段的最新记录，无法重建此前完整建设过程。
- 完成、继续和修改范围仍按工程阶段分开查看。封存阶段不会补采，平台只把它已有的记录保存为历史基线。

存储使用 V26 中的不可变分段清单，未变化的原始分段按内容哈希在同一工程中复用，不为每个时间点复制完整场景。模型和贴图在查看历史时按需转换，旧转换缓存可清理后重新生成，原始历史仍保留。删除工程同时删除历史清单、原始分段及后续清理的转换缓存。历史会持续占用存储，变化越频繁、范围越大，增长越快；当前不自动删除历史。

## 三维点选

- 电脑点击、手机轻点方块，显示高亮边框、中文名称、X/Y/Z、方块状态、附加层和该位置已有的施工记录。
- 点选对应实际模型面片，兼容非整块模型、负坐标、透明贴图以及高度裁切。移动、旋转手势不触发查询。
- 历史画面从该次模型的不可变原始数据查询，不回读最新方块。施工记录截止到该分段的采集时间，最多展示最近 50 条，并提示是否还有更早记录。
- 没有记录不能判断建造者；某人过去放置过方块不等于当前方块归他所有。公共页面不提供箱内库存、聊天和玩家账号标识。
- 手机全屏保持纯模型与退出按钮；请退出全屏后点选。电脑全屏可直接点选。
- 旧转换缓存若没有分段时间，会显示时间未知，不把当前行为记录混进旧画面；最新模型会重新生成以补全查询所需元数据。

## 接口

以下接口遵循现有工程公开访问规则，不增加写入世界的能力：

- `GET /api/public/projects/{id}/phases/{revision}/scene/history`：按保存时间倒序返回 100 条；`before` 为上一页末尾的保存时间。
- `GET .../scene/history/{snapshot}/status`：按需转换不可变历史画面。
- `GET .../scene/{build}/block?x=...&y=...&z=...`：查询此模型版本的方块与截至其采集时间的施工记录。

## 验证

- 后端集成测试覆盖版本冻结、拆除后的旧画面、分段复用、负坐标、无记录区域、范围越界、阶段隔离、公开列表和删除撤销访问。
- `node scripts/verify-project-history.mjs`：浏览器桌面/触屏点选、拖动不误选、历史播放、切换时保留视角和快速切换竞态。
- `node scripts/verify-project-fullscreen.mjs`：原生全屏、手机横竖屏、浏览器不支持/拒绝全屏时的回退与清理。

浏览器脚本使用可控场景和响应验证交互，不代表真实游戏采集验收；发布时另检查线上真实工程的历史保存、真实模型转换和点选接口。
