# 功能与入口

| 导航 | 功能 | 需要的组件 |
| --- | --- | --- |
| 数据总览 | 趋势、维度、档案、工程与运行摘要 | 平台 + 采集 |
| 服务器档案 | 按服务器整理记录、封存与说明 | 平台 |
| 玩家统计 | 累计/每日数据、排行、分类明细 | 采集 |
| 行为统计 | 游玩会话、聊天、坐标行为与筛选 | 相应事件能力 |
| 世界地图 | 匿名访问、多维度、坐标跳转 | MipMap |
| 施工工程 | 选区、贡献、阶段、二维/三维、GLB 导出 | 原生新版本配置 + 场景转换 |
| 世界故事馆 | 14 类可视化、日期范围、统计说明 | 平台记录 |
| 服务器日报 | UTC+8 统计汇总与建设变化 | 平台记录；不自行发送 QQ |
| 运行状况 | 整机及游戏进程曲线、样本缺口 | 原生主机采样 |
| 服务器控制台 | 受控命令与进程生命周期 | 独立主机执行端 |
| AI 助手 | Agent 权限、MCP 配置与调用 | 独立 Agent 主机 |
| 备份中心 | 每服分类、分页、每日时间、下载恢复 | 游戏主机执行端 |
| 账号管理 | 后台创建管理员/只读账号 | 管理员 |
| 平台设置 | 采集连接、存储、数据保留 | 管理员 |

「找功能」支持按关键词寻找入口，例如聊天、导出模型、备份、卡顿。只读账号不会获得管理员功能。

## 世界故事图表

伙伴与日常：作息热力图、活动河流、服务器时钟、玩家气泡、玩家雷达。

建造与协作：建筑协作网络、贡献桑基图、材料矩形树图、建设榜回放、施工旭日图、成长时间轴。

探索与运行：建设热区、地下施工分布、运行分布。

协作表示共同参与记录，不代表好友关系；材料数量是记录到的行为次数，不代表当前库存；移动距离是采样估算，不包含传送。详见页面统计说明。
