# 备份中心

按服务器分组、分页浏览归档，可筛选、下载、查看详情、编辑备注、设为永久保留或删除。新任务默认只备份游戏世界，完整目录归档有独立范围标记。

## 一次备份的状态

1. 中央创建任务，由对应的游戏主机执行端领取。
2. 执行端协调快照、复制、释放快照、压缩与本地校验。
3. 上传归档，平台检查长度、摘要、文件清单与档案身份。
4. 成功后出现在该服备份列表，可以下载。

任务正在运行、本地目录增长、上传完成、文件校验通过与实际恢复成功是不同状态。页面保留失败和不确定状态，不把它们当作成功备份。

## 自动备份

按服务器配置每天几点执行，可以结合数量/天数保留策略。中央服务须持续运行，执行端须在线。永久、手动及最终封存备份不参与普通自动轮换；页面显示具体保护规则。

## 恢复

管理员在详情中进入恢复向导，选择独立空目录和恢复模式。WORLD 归档需要预先准备匹配的运行程序。不能把内容校验通过当成实际进服验证。工程、平台数据库和地图瓦片有各自的存储位置，世界归档不会替代它们。

所有管理与下载操作要求管理员权限，变更校验 CSRF。公开地图访客与 Agent 凭据不能下载游戏备份。
