# 安装与更新

平台从 [快速开始](getting-started.md) 安装；正式部署、持久数据和回滚见 [部署指南](deployment.md)。

游戏端必须匹配 [兼容矩阵](compatibility.md)。原生构建见 [采集器](../collector/README.md)，地图运行库见 [地图模块](../map/README.md)。更新前正常停服，保留原配置与凭据，不删除世界或未确认的上传队列。

MCP 源码包解压后执行 `npm ci --ignore-scripts`，保留原 Agent 凭据，更新客户端配置的绝对路径并重启 MCP 进程。无需新增公网端口。完整步骤见 [MCP](../mcp/README.md)。

执行端源码包需要 Node.js >=22；保留私有配置，按 [备份说明](../backup/README.md) 更新。公开源码包不包含预配置账号、游戏世界或 Minecraft 服务端。

`/ai` 是可选功能，需已有 DSH 与 QQ 桥接；其验证范围见 [桥接说明](游戏内AI与DSH.md)。
