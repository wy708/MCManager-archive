# 网页账号管理

## 使用方法

管理员登录后，进入「账户与设置 → 账号管理」创建账号，设置初始密码，并选择「管理员」或「只读账号」。登录页没有注册入口，未登录和只读用户均不能调用创建账号接口。

所有用户都可以点击右上角账号菜单中的「修改密码」，填写原密码、新密码和确认新密码。修改成功后需要重新登录；其他设备上的旧登录在下次请求时失效。密码至少 12 位，UTF-8 编码不超过 72 字节，不能与原密码相同；两次确认必须一致。

账号名称使用 3–40 位字母、数字、点、横线或下划线，以字母或数字开头，不区分大小写。账号列表不显示密码，数据库只保存 BCrypt 哈希。

| 功能 | 管理员 | 只读账号 |
| --- | --- | --- |
| 服务器档案、玩家统计、行为及聊天记录 | 查看、管理 | 查看全部服务器 |
| 世界地图、公开工程二维/三维画面与历史 | 查看 | 查看 |
| 日报、运行状况 | 查看 | 查看 |
| 创建、修改、封存或删除工程；后台 GLB 导出 | 可以 | 不可以 |
| 控制台、备份下载、恢复、凭据和 AI 助手管理 | 可以 | 不可以 |
| 创建账号、启用或停用其他账号 | 可以 | 不可以 |
| 修改自己的密码 | 可以 | 可以 |

停用账号会撤销已有登录；重新启用后也必须重新登录。不能停用自己，平台至少保留一个可用的管理员。公开地图和公开施工档案的访问规则不受影响。只读账号没有后台模型导出入口，公开三维查看仍会向浏览器提供显示所需的模型数据。

## 从旧版本升级

V27 新增网页账号表。第一次升级会用现有 `MCM_ADMIN_USERNAME`、`MCM_ADMIN_PASSWORD` 初始化管理员，原账号密码可以继续登录。已有网页账号后，这两个变量只作为历史部署配置，不再覆盖数据库中的密码，也不会因为修改变量而自动新增管理员。账号随平台数据库一起备份。

新增接口：管理员使用 `GET/POST /api/admin/accounts`、`PUT /api/admin/accounts/{id}/enabled`；用户使用 `POST /api/auth/password` 修改自己的密码。所有写接口保留 CSRF 校验。只读权限使用后台 GET 白名单，管理接口仍默认要求管理员，不仅仅隐藏页面按钮。改密按账号限制原密码验证次数，10 分钟内最多 5 次。

## 验证

- `WebAccountsTest`：创建权限、CSRF、重复名称、字段校验、哈希存储、只读接口边界、改密、全部旧会话撤销、停用/启用和最后管理员保护。
- `node scripts/verify-web-accounts.mjs`：使用真实本地后端和独立数据库，从网页创建两种账号、手机尺寸下修改密码、检查旧登录失效，并重启后端进程验证新账号及新密码持久化。不是模拟登录响应。
- 账号改动与档案、采集、会话传输相关测试共 82 项通过；手机使用触屏浏览器模拟验收。

这次更新不涉及游戏服插件、MCP 凭据或游戏世界文件。
