# 世界地图透明方块修复

地图插件版本 **1.0.3+mcmanager.5**。此更新针对 MipMap 二维世界地图，与统计采集器独立升级，MCP 不变。更新采集器 0.35.0 或 0.36.0 不会自动替换地图插件；请以启动日志中的 MipMap 版本为准。

## 修复内容

原来的地图只保存每个 X/Z 最上面一个方块。火把、花草、玻璃贴图的透明区域没有下层，所以露出网页的深色背景。现在采集实际的下层方块，由下往上叠加，保留普通玻璃的边框、染色玻璃的颜色和下方地形。还覆盖作物、铁轨、树叶等已支持的透明材质，主世界、末地和地狱层地图共用叠图规则。

不会把所有空白涂成草地，也不会沿用上一张图片的地面当作当前事实。方块被拆掉、地面改变后，重新采集会完整替换该列，清除旧残影。原来的缩放层级、坐标跳转、公共链接和多人服务器隔离保留。

## 已安装游戏服怎么更新

1. 正常输入 `stop` 停服，确认游戏进程退出。
2. 解压 `MCManager-Map-Update-1.0.3-mcmanager.5.zip`。
3. 双击“更新地图.cmd”，输入游戏目录，例如 `E:\bedrock-server-1.26.61.1`。
4. 用原来的 `03-start.cmd` 启动，确认加载 `mipmap v1.0.3+mcmanager.5`。

更新程序只替换地图 wheel，并从地图黑名单恢复已支持的透明装饰方块。原版黑名单曾为渲染缺陷屏蔽花草和部分玻璃板，这些项目需要解除。其他黑名单项、上传地址、密钥、游戏配置、世界和框架保留。原插件和配置备份在游戏目录 `.mcmanager-map-updates`，如仍想隐藏某种透明方块，可更新后重新加入 `plugins/mipmap/config.toml` 的黑名单。

不要同时保留多个版本的 `endstone_mipmap-*.whl` 在 `plugins` 根目录。更新器会将旧版本移入备份目录，不修改 EndstoneRuntime、LeviLamina 或网络补丁。

## 为什么旧地图不会立刻全部变好

旧记录没有玻璃、火把下方的数据，不能凭空补齐。升级后，已加载区块会逐步重新采集；玩家回到对应区域后，新图片自动替换。地图插件不会为了更新地图自动加载整个世界。只刷新网页、只升级 平台主机、只更新统计采集器，都不能补出缺失的下层。

## 性能与边界

采集逐帧进行，每帧最多读取 256 次，目标预算默认约 1 毫秒，可通过 `surfaceBudgetMs` 调整至 0.2～4 毫秒。单次游戏接口或系统调度仍可能超时，不承诺绝对上限。低 TPS 时降低采样频率，扫描过程中区块卸载即停止读取。不会生成额外区块。

单列最多保留 64 个可见层；空气不占层数。极深的透明堆叠会标为未完整采集，缺少的地面不会伪造。层数上限与每帧读取预算用于控制传输、内存和游戏线程开销，不限制地图的公开访问范围。高度阴影保留贴图透明度，避免海拔着色再次填出黑方块。

材质识别沿用当前固定版本原版资源，421 类存在透明贴图的方块纳入采样提示；这是二维俯视纹理叠加，不是光线追踪或三维透明实体还原。自定义资源包仍需要对应材质适配。
