# 施工工程三维预览与模型导出

本功能最初随 Windows BDS 1.26.61.1 采集器 **0.33.0**、平台数据库 V23 发布；后续采集器版本包含这些功能。2026-11-08 新增移动、旋转按钮并修复旋转中心，按钮只需刷新网页；实际群系配色需要更新采集器至 **0.36.0** 后重新采集。

## 怎么查看

打开原来的公开工程链接，点击“三维建筑”，或在链接末尾加 `#model`。鼠标拖动旋转、滚轮缩放、右键平移；手机单指旋转、双指缩放和平移。

- 电脑端的“移动视角”提供前进、后退、左移、右移、上升、下降六个按钮：点按微调，长按连续移动。前后左右跟随当前观看朝向在水平面移动，上下改变高度；保持观看角度和缩放比例。“回到全景”找回整个工程，键盘 Tab 选中按钮后也可用 Enter 或空格操作。手机端隐藏移动和旋转按钮，使用单指旋转、双指缩放和平移。这里只移动浏览器视角，不移动游戏中的玩家，不写入工程或采集数据。
- “围绕模型旋转”提供向左、向右、向上、向下四个环绕按钮，也可长按。拖动旋转和按钮旋转均保留你平移、缩放后的观察中心，不再自动跳回工程中心。修改显示高度也不移动视角。只有点击“重新居中”才对准当前高度范围的模型中心，并保留观看角度和缩放；“回到全景”和“显示全部模型”按各自范围重新取景。
- 最低和最高显示高度填写后，点击“查看这一层”。高度仅保存在本浏览器的 localStorage，按工程 UUID 区分，不向后台保存，不影响采集。刷新、重新打开、切换阶段后仍使用该工程的高度；清除浏览器网站数据后重置。
- “全部高度”取消裁切；“显示全部模型”同时取消高度裁切并回到全景。“全屏查看”请求浏览器原生全屏，画布铺满屏幕，保留进入前的观察中心和缩放。手机全屏只显示模型与右上角“退出全屏”，电脑保留下方浮动工具栏；隐藏工程说明与统计文字。按 Esc、浏览器退出操作或“退出全屏”返回。浏览器不提供或拒绝全屏接口时，自动使用铺满可用页面的模式，无法强制隐藏该浏览器自己的地址栏。手机横屏同样隐藏按钮，并为退出按钮预留安全边距。
- “显示动物和怪物”默认关闭，仅改变显示，不影响采集。盔甲架及装备、展示框和告示牌始终显示；掉落物和玩家不采集。
- 二维工程地图默认完整显示范围，支持拖动、滚轮、双击、双指和加减按钮缩放；“全景”返回完整范围。仍只显示该阶段工程范围内已保存的地图，不开放周围世界。

## 管理员导出

登录后台 → **施工工程** → 对应工程卡片 → **导出 3D 模型**，选择阶段和是否包含动物、怪物，再点“下载 GLB 模型”。

GLB 内嵌贴图，可导入 Blender 等支持 glTF 2.0 的软件。导出的是平台最近成功转换的场景；水和岩浆保留快照形状，贴图动画导出为第一帧，不模拟液体或动物运动。文件坐标相对于场景原点，原始世界原点保存在 `extras.minecraftOrigin`。

下载接口校验管理员登录和服务器/工程归属。公开工程页没有导出按钮，公开资产接口不能下载 GLB。公开网页为了显示模型仍会获取几何与贴图，因此管理员导出限制并不等于阻止技术性复制。

## 记录和形状

两个点仍限定 X/Z 水平矩形，扫描覆盖维度所有高度，方块保留 X/Y/Z、类型和状态。首次扫描包括已有建筑和天然地形。原版资源模型由平台的 MiEx 转换器生成，原木端面/树皮、火把朝向、藤蔓附着、楼梯、半砖等不再统一套六面立方体。

0.32.0 已有的方块记录也可转换新模型，不必为修正木头和火把重新建工程。0.33.0 才新增附加含水层、告示牌文字、展示框物品、实体及可见装备的采集；旧记录缺少的内容会明确提示，不能凭空补齐。已封存工程不自动补采，需要继续施工进入新阶段。

动物、怪物是采集时的姿态，不是实时游戏直播。箱内库存、书籍内容和玩家身份字段不会作为场景外观上传。群系精确采样尚未接入当前游戏版本，植物与水使用默认群系配色，并提示这一限制。

## 更新、封存和性能

- 8×8×8 分段采集，只读已加载区块，不自动加载或生成世界。优先扫描玩家附近高度和发生改动的分段，再周期补扫。
- 每 tick 目标预算约 0.75 毫秒，最多处理 256 个方块位置；每个位置读取主层和附加层。实体外观另按时间和内容预算分帧。单次游戏 API 或系统调度仍可能超过预算，不保证零影响。
- 压缩和 HTTP 上传在工作线程运行，最多积压 8 个分段；脏分段队列最多 2048 项。超额由后续扫描补齐，附加外观截断会标记不完整。
- 网页每 5 秒查询转换状态，多个访客共用转换结果；活动工程合并更新，转换期间保留旧画面，不周期清空重画。平台最多一个转换任务执行、四个排队；失败/超时会保留提示，不把半份文件标成成功。
- “完成”冻结已经上传的分段快照，不等待未上传数据；“继续”或“修改范围”建立新阶段。删除工程立即撤销所有公开模型和下载，稍后清理转换缓存。
- 各分段采集时间可能不同，离线只显示最后记录，空白不等于空气。模型默认显示完整已转换几何，不按方块数偷偷裁掉后半部分。极大工程仍可能超出转换内存、超时或浏览器显存；分块流式显示尚未实现。

## 更新已有 Windows 游戏服

以下是首次补齐 0.33.0 场景采集功能的历史步骤；已经使用更新版本的游戏服不要降级。当前 0.36.0 的更新方式见[地图与模型配色更新](地图与模型配色更新.md)。按钮不依赖游戏端更新。

1. 正常 `stop` 停服并确认进程退出。
2. 备份 `plugins/archive-collector`。
3. 解压 `MCManager-Collector-1.26.61.1-0.33.0.zip`，将 `plugins` 合并到游戏目录，覆盖 DLL 和 manifest。
4. 保留原来的 config、data、框架、地图、世界。用原来的 `03-start.cmd` 启动，确认日志显示 0.33.0。

不重新运行首次安装程序，也不修改端口或网络设置，继续保持 `netherNetPatch.enable=false`。MCP 不用重复更新。

## 验证与边界

- `scripts/verify-scene-shapes.mjs`：81 组原版方块状态的形状、材质分面和轴向检查；这是构造数据回归，不冒充真实游戏操作。
- `scripts/verify-project-model.mjs`：隔离 BDS 的实际扫描、外观、修改、封存、继续、离线查询以及后台转换/下载。
- `scripts/verify-scene-page.mjs`：真实后台上的桌面、手机预览、高度记忆、全屏和管理员按钮下载。
- `scripts/verify-project-navigation.mjs`：构造场景验证六向移动、四向环绕、固定旋转半径、平移缩放后按钮/鼠标保留观察中心、显式居中、裁切不跳位、点按和长按停止、触摸取消、键盘、桌面全屏及按钮尺寸。
- `scripts/verify-project-fullscreen.mjs`：验证桌面及手机竖屏/横屏的原生全屏、缺少接口和拒绝请求时的页面铺满、手机只留退出按钮、单指/双指手势、画布覆盖整个视口、退出同步、焦点与页面滚动恢复。
- `scripts/verify-scene-biomes.mjs`：真实转换器验证不同群系草色、草侧面与泥土分开染色、缺少群系时的说明以及 GLB 导出。
- `scripts/verify-project-view-controls.mjs`：二维地图拖动、滚轮、双指、全景和分工程本地设置。
- `scripts/verify-scene-renderer.mjs`：真实采集场景的几何与 GLB 导入、材质、中文告示牌、展示框、装备和活动实体开关。

目前不承诺逐个还原所有原版内容：全部生物变种和姿态、手持/副手物品、染色/纹饰/附魔特效、发光照明、展示框地图内容、邻接缺失区块边界以及大型场景仍有待完善。自定义资源包上传和阶段资源版本固定尚未接入；该版本资源和模型验证针对原版场景。缺失模型或贴图会列出说明，不用立方体假装成功。

转换器构建、资源固定版本及开源许可证见 [scene/README.md](../scene/README.md)。
