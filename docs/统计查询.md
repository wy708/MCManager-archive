# 统计查询

以下均为管理员会话接口。所有服务器范围包括已封存、离线服务器，历史数据不会因为采集器未在线而消失。

通用筛选参数：`serverId`、`playerKey`、`fromDate`、`toDate`、`dimension`。省略服务器表示全部；省略日期表示累计。日期是平台统计时区的本地日期，起止均包含。

| 接口 | 内容 |
| --- | --- |
| `GET /api/metrics` | 指标、名称、单位、SUM/MAX 及是否只允许估算 |
| `GET /api/statistics/summary` | 去重玩家、会话、最长会话、挖掘子分类、全部指标与质量/算法明细 |
| `GET /api/statistics/daily` | 每日趋势；默认最近七天，最多一次 366 天 |
| `GET /api/statistics/servers` | 各服对各指标的贡献，保留质量与算法版本 |
| `GET /api/statistics/dimensions?metric=online.millis` | 按维度汇总指定指标，保留质量与算法版本，不以固定页长截断维度 |
| `GET /api/statistics/breakdown?metric=blocks.mined` | 指标按分类对象、维度、质量、算法分解；挖掘可筛 `category=WOOD/ORE/OTHER` |
| `GET /api/players` | 分页玩家列表，可通过 `search` 搜索当前或历史名字；百分号和下划线按文字搜索 |
| `GET /api/players/{key}` | 全局玩家档案、全部历史名字与参与服务器 |
| `GET /api/deaths` | 分页死亡时间、死因、维度和可识别来源类型 |
| `GET /api/sessions` | 分页会话，起点、最后检查点、已确认在线时长和结束原因 |
| `GET /api/collectors?serverId=...` | 采集器版本、最近请求/报告时间、积压、当前能力与历史覆盖 |

分页使用 `page=1`、`pageSize=25`，单页最多 100，页码最多 10000；响应是 `{items,total,page,pageSize}`。

## 数值与缺失

累计值使用十进制**字符串**返回，防止 JavaScript 超过安全整数范围。不要对不同指标求和；不同质量和算法版本在 `measurements` 中保留，MAX 指标跨服务器、日期、版本都取最大值。

`value=null` 表示筛选范围内没有该指标的采集覆盖；启用并观测到零才返回 `"0"`。维度筛选会排除未声明维度能力的覆盖。`coveredServers` 表示该范围内曾声明启用并被观测到的服务器数，`selectedServers` 是查询范围的全部档案数；两者不代表期间没有断线或漏采。

玩家按稳定身份去重，不将各服玩家人数相加。列表和档案中的当前名字、首次/最后观测时间是全局身份信息；各服参与时间在 profile.servers 中提供。同名不会自动关联为同一玩家。

玩家档案切换服务器范围时保留当前身份，统计随范围更新。若玩家从未参与所选档案，统计接口返回 404，网页依据参与历史显示该范围无记录。实服与浏览器核对见 [验证范围](testing.md)。

`woodBlocks`、`oreBlocks` 是 `blocks.mined` 的子集，不再加进总挖掘数。当前分类算法识别 Minecraft 命名空间的原木/木块/菌柄/菌核与矿石/远古残骸，不把所有名字含 stem 的植物当作树木。

## 在线与会话

在线时间是已接收检查点的累计，不会根据当前时间外推。在日期窗口内，在线指标按实际区间切分；会话次数和最长会话针对**开始时间在窗口内**的会话，后者是该会话已观测的完整长度。

`sessionCount` 保留历史口径，统计全部会话记录。`confirmedJoinCount` 统计 `startReason=JOIN` 的会话。若范围内只有旧版会话或没有已分类记录，该值为 `null`。全服汇总也只计确认过的进服。`/api/sessions` 和 MCP 玩家上下文暴露 `startReason`，其中 `OBSERVED` 代表采集开始时已经在线，`null` 代表旧版未区分。`endReason=CAPTURE_STOPPED` 表示采集结束，玩家可能仍在线。停用期间留空，最长会话取单条记录，不拼接跨缺口的记录。

会话可以跨维度，因此维度筛选下 summary 的会话次数和最长会话为 null，sessions 接口明确拒绝维度筛选。查看单维度在线请查询 `online.millis`。

- `OPEN`：最后检查点较新且未正常结束，不等于已经向游戏服务器实时确认在线。
- `STALE`：超过 120 秒没有该会话检查点，仅保留已确认时长。
- `ENDED`：已正常结束。
- `INTERRUPTED`：同身份新会话替换旧会话；旧会话只结算到最后检查点。

采集器的 `CONNECTED` 表示近 120 秒收到合法 HTTP 请求；`REPLAYING` 还表示最近报告的队列有积压；`STALE`/`UNCONNECTED` 分别表示请求陈旧或从未连接。请求活跃不等于全部游戏行为已成功采集。
