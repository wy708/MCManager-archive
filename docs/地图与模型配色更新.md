# 地图与模型配色更新（2026-11-08）

这次涉及两个独立插件：二维世界地图使用 **MipMap 1.0.3+mcmanager.5**，三维工程场景使用 **采集器 0.36.0**。两个更新包都需要检查；只升级采集器不会更新地图插件。

## 游戏服更新

可以先下载到游戏目录外，等玩家下线后再操作。不要在游戏运行中覆盖 DLL 或地图 wheel。

1. 在游戏控制台正常 `stop`，确认游戏进程退出。
2. 备份 `plugins/archive-collector`。解压 `MCManager-Collector-1.26.61.1-0.36.0.zip`，将包内 `plugins` 合并到 **E:\bedrock-server-1.26.61.1**，只覆盖 `archive-collector.dll` 和 `manifest.json`。保留 config、data、世界和框架。此包不是放入含 `03-start.cmd` 的执行端目录。
3. 若 MipMap 仍是 mcmanager.4，解压 `MCManager-Map-Update-1.0.3-mcmanager.5.zip`，运行其中的“更新地图.cmd”，输入同一游戏目录。它会备份旧地图 wheel 和配置，保留上传地址、密钥并恢复已支持的透明方块。不要手工把新旧两个 wheel 一起留在 plugins 根目录。
4. 用原来的 `03-start.cmd` 启动。检查日志显示采集器 **0.36.0** 和 `mipmap v1.0.3+mcmanager.5`。
5. 玩家进入需要更新的地图或工程区域，等待已加载区块分批重采。再刷新网页。

0.36.0 包含 0.35.0 的全部采集功能和批量补传优化。MCP、执行端、端口和游戏网络设置不变，不要重新运行首次安装程序。

## 二维世界地图

火把、花草、作物、铁轨、玻璃、染色玻璃及玻璃板等按实际采集层从下往上合成，透明处能看到对应草地、耕地、沙子或石头。放在地面或地下的玻璃，只要该列在当前表面或洞穴层可见，按同一规则叠加；不透视完整实心地面下面的封闭建筑。旧版地图未上传下层，不能仅靠刷新网页补出，也不伪造草地填空。

## 三维模型

- 新采集场景记录每个方块位置的实际生物群系，植物按对应群系着色，避免所有地点都用平原的默认草色。只读已加载区块，仍使用原有分帧预算，不为采集加载新区块。
- 修复草方块侧面的泥土底图被额外染绿；草顶和草侧覆盖层分别应用配色。
- 新增四向旋转按钮、重新居中，鼠标、手指和按钮旋转保留平移缩放后的观察中心，点击“重新居中”才对准当前显示范围。保留按工程保存的浏览器高度设置。

网页按钮和侧面配色修复由 平台主机 网站提供；当地群系颜色需要新的采集数据。旧阶段没有群系记录时仍会明确提示默认配色；已完工阶段保持封存，需“继续工程”开启新阶段才会补采。不会通过种子或附近植被猜测旧阶段的群系。颜色不包含客户端光影、天气和可调群系混色半径，不承诺与手机截图逐像素一致。

## 验证

三维采集使用隔离的真实 BDS 1.26.61.1 测试服，群系与游戏发给客户端的区块数据进行独立核对；草色转换使用平原、丛林、沙漠和缺少群系四种输入。网页使用线上已保存工程，检查桌面与手机尺寸的移动、旋转、居中与全屏。真实手机上的最终显示仍以使用者设备为准。世界地图已对透明叠层、下层类型、移除后的替换及旧数据兼容进行回归检查。
