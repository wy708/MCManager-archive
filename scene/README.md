# 工程场景转换服务

目标是读取工程分段快照，以原版资源的真实模型、贴图和状态生成网页场景。转换在平台执行，不打开游戏存档，也不运行在游戏线程。公开访问沿用平台的同一个端口。

## 当前实现

- 原生采集增加额外方块层、告示牌等可见方块数据、非玩家实体及可见装备（掉落物排除）。只保留外观字段，不上传箱内库存、书籍或玩家身份字段。
- 平台 V23 保存场景数据，保留原有工程范围、阶段、封存和删除规则。
- MiEx 转换器使用固定源码和资源版本，补丁保存在 `patches/`；不会用方块立方体代替缺失的模型。缺失项目列入结果说明。
- 同时只运行一个转换任务、最多四个排队任务；相同工程的多个访客共用任务。活动工程合并更新，失败后延迟重试。超时会终止进程及子进程，不会把半份模型发布成成功结果。
- 已生成场景写入持久目录，重启可以重新读取。封存阶段沿用其生成结果。工程删除后公开读取立即失效，缓存清理任务移除文件；旧版本缓存保留一小时供正在查看的页面使用。
- 网页按真实几何体绘制，更新过程中保留旧画面。动物、怪物等活动实体默认隐藏，可在预览中开启；切换只改变显示，不重新采集或转换。盔甲架及装备、展示框和告示牌不受开关影响。
- 首次预览从工程范围内、快照时间之前记录到的最低放置高度开始，包括所有贡献者；没有放置记录时用场景地表估计，并明确提示来源。浏览器已保存的工程高度优先；“施工起点”恢复自动范围。手动降低高度或选择全部高度后才读取相应地下内容。
- 平台按高度流式筛选场景，网页只为选中范围创建几何；跨越边界的面仍精确裁切。此优化减少浏览器传输和渲染，不删除采集记录、不改变完整场景转换范围，也不影响历史记录查询。

## 后台模型导出

后台工程卡片提供“导出 3D 模型”，可选择已记录阶段及是否包含活动实体。默认只导出建筑、地形与固定装饰；GLB 内嵌全部使用的贴图，不依赖平台链接。纹理动画导出为第一帧，水/岩浆保留快照形状，不在建模软件内模拟流动。原始坐标保存在 GLB 的 extras.minecraftOrigin 中，几何体使用相对原点以避免大坐标精度损失。

下载前必须在对话框确认最低和最高 Y，初始值优先采用浏览器保存的工程高度。选中范围按方块层计算（最高 Y 层包含在内），跨边界三角形裁切并插值贴图坐标。任务固定使用打开对话框时准备好的场景版本，在平台转换队列中生成；范围导出缓存一小时。导出不重新扫描游戏。Blender 中使用“文件 → 导入 → glTF 2.0”，切换材质预览查看内嵌贴图。

`/api/servers/{server}/projects/{id}/phases/{revision}/scene-export/...` 仅允许管理员会话，校验服务器与工程关系。公开工程页不提供下载入口，公开资产接口不提供 GLB 文件。公开网页仍必须读取渲染所需几何与贴图，因此这不是防止技术性复制的 DRM。

## 构建和启动

需要 Git、Python 3 和 JDK 21。输出目录必须为空，脚本不会删除调用者的目录：

```text
python scene/build.py --output <绝对路径/scene-runtime>
```

构建时下载并校验固定版本的资源，来源见 `sources.json`。Java 26.3 资源仅作为 MiEx 的基础几何和字体来源，Bedrock 资源为 1.26.60.5；这不意味着所有资源已逐项对照 1.26.61.1 验证。

设置后台环境变量：

```text
MCM_SCENE_RUNNER=<scene-runtime 的绝对路径>/run.mjs
MCM_SCENE_DIR=<持久目录>/scenes
```

转换器通过 Node 调用 Java。Linux 使用 Xvfb 私有虚拟显示，禁止 X11 TCP 监听；没有对外地图或转换服务端口。后台 Dockerfile 包含所需构建步骤。未配置转换器时，页面明确提示服务尚未安装。

## 验收入口

- `node scripts/verify-scene-heights.mjs`：隔离真实后端与浏览器，合成多高度场景验证默认范围、浏览器记忆、传输/顶点减少、后台范围导出、GLB 内嵌贴图与公开下载权限；不代替真实方块外观验收。
- `node --test scene/glb.test.mjs`：GLB 高度裁切、纹理坐标插值、实体过滤和空范围处理。

- `scripts/verify-project-model.mjs`：真实 BDS 1.26.61.1、原生插件、隔离数据库、封存/继续/离线流程。设置 `MCM_SCENE_RUNNER` 后还调用真实转换器，并通过 `verify-scene-page.mjs` 检查公开工程页面的桌面和手机显示。
- 后端 `constructionRenderingCachesFrozenScenesAndRevokesDeletedAssets`：用最小转换进程检查重复请求、重启缓存和删除撤销，不代替模型真实性验收。
- `scripts/verify-scene-renderer.mjs`：独立几何渲染回归，输入使用真实采集产生的转换结果。
- `scripts/verify-scene-shapes.mjs`：方块形状与贴图回归，包含普通箱、陷阱箱和末影箱的四个朝向。`fix_chest_uvs.py` 修正内置箱子模型倒置 Y 轴导致的箱盖内外贴图互换；不改变几何形状或采集记录。
- `scripts/verify-scene-chests.mjs`：对比修复前后真实采集的箱盖画面。转换资源更新后须重新生成已有场景缓存及 GLB；刷新网页不会自行改变旧缓存。当前快照不包含箱子配对信息，不能仅凭相邻位置推断双箱。

## 尚未达到完整交付的部分

自定义资源包上传、版本固定和阶段资源封存尚未接入，目前面向原版资源。实体采集按时间预算跨帧继续；极端密度或内容超出单段预算时会返回不完整标志。全部实体姿态/手持物、发光效果、展示框地图内容和大型工程分段渲染仍需补齐或验证。0.36.0 采集器为 BDS 1.26.61.1 场景提供实际群系记录，转换器先映射基岩版群系名称再着色；旧记录缺少群系时明确提示默认配色。草方块侧面底图不重复染色。客户端光影、天气与群系混色半径仍不复刻。动物姿态来自采集时快照，不是实时游戏直播。当前分段实体采集遇到数量或内容预算会返回不完整标志，网页不得把它称为完整场景。此版本支持原版常见方块形状及场景外观，不代表上述未完成功能已验收。
